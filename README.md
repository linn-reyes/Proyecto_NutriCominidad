# NutriComunidad

Plataforma web que conecta comercios, organizaciones sociales y familias para aprovechar los alimentos que aún pueden consumirse y promover una alimentación saludable.

## Descripción

En muchas comunidades hay familias con dificultades para acceder a alimentos saludables, mientras que mercados, tiendas y restaurantes desechan cada día productos que todavía son aptos para el consumo. Además, algunas personas no saben si su alimentación cubre sus necesidades ni qué pueden comer de acuerdo con su presupuesto.

NutriComunidad busca:
- Reducir el desperdicio de alimentos en comercios y mercados.
- Facilitar que los alimentos lleguen a las familias que los necesitan, a través de organizaciones sociales.
- Sugerir recetas y menús económicos con los alimentos disponibles.

Esta versión es el maquetado del sistema, con datos de ejemplo guardados en arreglos de objetos de JavaScript. En una siguiente etapa se conectará a una API.

**Sitio publicado:** https://proyecto-nutri-cominidad.vercel.app

## Instalación

1. Clona este repositorio.

2. Navega a la carpeta del proyecto:
   - cd [carpeta del proyecto]

3. Instala las dependencias:
   - npm install


## Características

- Inicio de sesión con tres tipos de acceso: usuario, comercio y organización.
- Módulos del usuario: recetas, recomendaciones, solicitudes de apoyo y preferencias alimentarias.
- Recetas económicas con sus ingredientes.
- Recomendaciones de menús ordenadas de la más económica a la más cara.
- Solicitudes de apoyo alimentario con su estado y prioridad.
- Preferencias y alergias declaradas de forma voluntaria.
- Mensajes cuando una lista no tiene registros o cuando un detalle no existe.
- Formularios con validación de campos.
- Diseño responsive para computadora y celular.
